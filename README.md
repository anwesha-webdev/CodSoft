# Personal Portfolio Website

A responsive personal portfolio website for showcasing my profile, skills, projects, resume, and contact information.

## Live Demo

Visit the portfolio here:

https://anwesha-webdev.github.io/portfolio/

## About

This portfolio introduces me as a web developer and highlights my frontend development work. It is built using HTML and CSS, with a clean layout that includes sections for an introduction, skills, projects, resume, and contact details.

## Features

- Responsive personal portfolio layout
- Hero section with profile introduction
- About Me section
- Skills section with progress bars
- Projects section with live project links
- Resume download link
- Contact section
- Social media links

## Technologies Used

- HTML5
- CSS3

## How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/anwesha-webdev/portfolio.git
```

2. Open the project folder:

```bash
cd portfolio
```

3. Open `index.html` in your browser.

## GitHub Pages Deployment

For GitHub Pages, make sure the files are placed directly in the root of the repository:

```text
index.html
style.css
assets/
README.md
```

Then enable GitHub Pages from:

`Settings` > `Pages` > `Deploy from a branch` > `main` > `/root`
